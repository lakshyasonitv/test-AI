## Required-field enforcement
Submit with each required field individually blank (not just all at once) to confirm each one is independently enforced.

## Inline vs on-submit validation
Note whether validation happens as the user types/blurs a field or only on submit — verify consistency between what's shown and what actually blocks submission.

## Form reset / cancel behavior
If a form has a reset or cancel action, verify it actually clears/discards changes rather than silently doing nothing.

## Multi-step form state
For multi-step forms, verify going back a step preserves previously entered data rather than resetting it.
