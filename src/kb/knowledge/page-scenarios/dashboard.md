## Data loads for the authenticated user
Verify the dashboard shows data scoped to the logged-in user, not another user's or global unfiltered data.

## Empty-state handling
For a brand-new account with no data yet, verify the dashboard shows a sensible empty state, not a broken layout or error.

## Widget/module independent failure
If the dashboard has multiple independent data widgets, one widget's data failure shouldn't crash the entire page.

## Navigation from dashboard
Verify primary navigation links/menu items from the dashboard lead to their correct destinations.
