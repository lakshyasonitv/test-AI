How a sentence becomes a test run

It reads your site first. Testbench looks at each page's buttons, fields and links, and follows links within your site. This step uses no AI credits.

It checks every step. Every button and field a test uses must exist on the real page. Anything the AI made up is removed before the test runs.

It runs in a real browser. Each test runs on its own and comes back with screenshots, a video, and a plain reason if it fails.
